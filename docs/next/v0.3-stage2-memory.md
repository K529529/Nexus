## M1：存储与工具

`app/memory.py` 管理 MEMORY.md、SCRATCHPAD.md、daily/YYYY-MM-DD.md 和 recovery。
Markdown 是权威源。条目使用完整 UUID 注释标记；正文可直接阅读。
读工具返回 ID 和内容 SHA-256 revision；修改和删除必须同时提供，拒绝模糊匹配、
过期版本、标记注入、路径越界、链接/junction 以及整文件覆盖。
手工编辑的无标记文本保留，不能通过 ID 工具误删；不自动迁移用户内容。

写入使用同目录临时文件、flush/fsync 和原子 replace。删除先持久化完整恢复记录，
再修改 Markdown；恢复追加原条目，保留后续写入，重复恢复无副作用，ID 冲突明确拒绝。
不声称跨文件事务、任意并发写入或断电后目录元数据持久性保证。
异步索引使用的 dirty 意图先于权威文件落盘；失效 epoch 先于更正/删除/恢复落盘。

工具：memory_write/read/search/forget/restore、scratchpad。Scratchpad 按单项 ID
添加、完成、撤销完成及可恢复清理。Search 在未连接 QMD 时准确返回 unavailable。
`[memory] enabled = false` 提供关闭入口；自定义/evaluation registry 默认不继承宿主记忆。

验证记录：首轮基线 576 passed / 10 skipped / 2 failed（Windows 进程清理）；
隔离系统临时目录、脱离 sandbox 后两项通过。M1 首轮全量 586 passed / 10 skipped /
1 failed：旧 Plan 测试固定断言只存在三个工具，已按新增六个公开工具更新。
9 项存储测试和 21 项存储/会话/模型配置定向测试通过。失败尝试保留于此。
